# Launcher 1.6.9 Hotfix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish launcher `1.6.9` with stream-verifiable updater signatures, a usable updater error modal, no update-bypass button, and smooth proportional Windows resizing.

**Architecture:** Keep the strict Rust streaming verifier and make the release producer fail closed unless it emits minisign `ED`. Fix updater UI wiring in the existing narrow renderer module. Put Windows aspect-ratio ownership and `WM_SIZING` rectangle arithmetic in a dedicated service used by startup and `set_window_layout`.

**Tech Stack:** Tauri 2, Rust, `windows` 0.58 Win32 bindings, vanilla ES modules, WebDriverIO browser mode, PowerShell, minisign 0.12, GitHub Actions.

## Global Constraints

- `v1.6.8` and its GitHub Release remain immutable; publish a new `v1.6.9` tag.
- Never accept legacy minisign `Ed` signatures in the launcher runtime.
- CI must use official `minisign-0.12-win64.zip` with SHA-256 `37b600344e20c19314b2e82813db2bfdcc408b77b876f7727889dbd46d539479`.
- Main/intro/install use `892 x 496`; updater uses `788 x 272`; each initial size is also its minimum and its aspect ratio.
- Window resize is Windows-native and smooth; no frontend resize feedback loop.
- Remove `#continue-without-update`; update failure can only be acknowledged or followed by closing the launcher.
- Work sequentially, do not force-push, and do not overwrite unrelated remote changes.
- Run tests per completed batch, not after every function; run the full Rust suite only through the final release gate.

- [ ] **Step 3: Implement the signature-format guard**

Add to `scripts/release-helpers.ps1`:

```powershell
function Get-MinisignSignatureAlgorithm {
    param([Parameter(Mandatory = $true)][string]$SignatureText)
    $lines = @($SignatureText -split "`r?`n")
    if ($lines.Count -lt 2) { throw 'Minisign signature is incomplete.' }
    try { $record = [Convert]::FromBase64String($lines[1]) }
    catch { throw 'Minisign signature record is not valid base64.' }
    if ($record.Length -ne 74) { throw 'Minisign signature record must be 74 bytes.' }
    return [Text.Encoding]::ASCII.GetString($record, 0, 2)
}

function Assert-StreamingMinisignSignature {
    param([Parameter(Mandatory = $true)][string]$SignatureText)
    $algorithm = Get-MinisignSignatureAlgorithm -SignatureText $SignatureText
    if ($algorithm -cne 'ED') {
        throw "Launcher updates require a streaming ED minisign signature; got $algorithm."
    }
}
```

#[test]
fn right_edge_preserves_main_ratio_and_minimum() {
    let current = ResizeRect::new(0, 0, 892, 496);
    let proposed = ResizeRect::new(0, 0, 1200, 496);
    let result = constrain_sizing_rect(WMSZ_RIGHT, proposed, current, MAIN_WINDOW_LAYOUT);

    assert_eq!(result.left, 0);

#[test]
fn top_left_keeps_opposite_corner_anchored() {
    let current = ResizeRect::new(100, 100, 992, 596);
    let proposed = ResizeRect::new(0, 20, 992, 596);
    let result = constrain_sizing_rect(WMSZ_TOPLEFT, proposed, current, MAIN_WINDOW_LAYOUT);
    assert_eq!((result.right, result.bottom), (992, 596));
    assert_eq!(result.width() * 496, result.height() * 892);

#[test]
fn updater_ratio_uses_vertical_corner_motion_when_it_dominates() {
    let current = ResizeRect::new(0, 0, 788, 272);

    let result = constrain_sizing_rect(WMSZ_TOPLEFT, proposed, current, UPDATE_WINDOW_LAYOUT);
    assert_eq!(result.width() * 272, result.height() * 788);
    assert_eq!((result.right, result.bottom), (788, 272));
    assert!(result.height() > 272);
}

- convert Tauri's Windows 0.61 `HWND` to the direct Windows 0.58 `HWND` by
  reconstructing it from the shared raw pointer value.

On non-Windows, native installation/update functions are no-ops so unit and
metadata builds retain a defined interface.
